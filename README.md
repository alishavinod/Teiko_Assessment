# Clinical Trial Cell Count Analysis

This project analyzes immune cell population counts from clinical trial samples.

The analysis uses SQLite for data management, Python for statistical analysis, and Streamlit for an interactive dashboard.

## Project Structure

```text
.
├── cell-count.csv       # Input dataset
├── load_data.py         # Loads CSV data into SQLite
├── analysis.py          # Data analysis and statistical tests
├── app.py               # Streamlit dashboard
├── requirements.txt     # Python dependencies
├── Makefile             # Setup, pipeline, and dashboard commands
├── cell_counts.db       # SQLite database generated by the pipeline
└── boxplots.png         # Generated boxplot output
